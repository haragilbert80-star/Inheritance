# Inheritance
Basic Inheritance

Demonstrates how a derived class inherits members and functions from a base class.

Output shows values from both base and derived classes.

Access Specifiers

Explains how private, protected, and public members behave in inheritance.

Shows compile errors when trying to access private members.

Constructor in Derived Class

Demonstrates constructor chaining between base and derived classes.

Shows how initializer lists call specific base constructors.

Destructor in Inheritance

Demonstrates order of destructor calls when deleting derived objects.

Derived destructor runs first, then base destructor.

Person–Student Example

Demonstrates inheritance with dynamic memory allocation.

Proper cleanup using destructors prevents memory leaks.

Multiple Inheritance

Shows how a class can inherit from two base classes.

Demonstrates constructor calls and function usage from both bases.

Virtual Inheritance

Solves ambiguity in multiple inheritance (diamond problem).

Ensures only one copy of the base class exists in the final derived class.
